SEG Light Box Installation and Maintenance Guide

SEG light boxes combine aluminum profiles, LED lighting and silicone-edge fabric graphics. Good installation planning keeps the graphic tension clean and helps the LED system stay serviceable.

Installation checklist

  • Confirm wall, floor or hanging installation method.
  • Check frame size and power access before production.
  • Install LED modules evenly and test brightness before closing the frame.
  • Insert SEG fabric corners first, then press edges evenly into the channel.

Maintenance tips

Keep spare graphics flat or rolled around a tube. Clean fabric with light dusting and avoid harsh chemicals. For retail programs, keep spare power supplies and LED strips on hand if the display runs daily.

Quote checklist

Send size, quantity, single- or double-sided display requirement, installation environment, graphic file and packaging needs.
