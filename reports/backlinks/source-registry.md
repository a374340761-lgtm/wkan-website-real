## 四、复制给 Codex 的完整 Prompt

你负责升级 **https://www.waikwantent.com/** 的现有 GitHub Pages 网站。项目资料提供的仓库是 **https://github.com/a374340761-lgtm/wkan-website-real**。公司中文名为 **广西伟群帐篷制造有限公司**，英文名为 **Guangxi WaiKwan Tent Manufacturing Co., Ltd.**，品牌为 **WaiKwan Tent**。请先读这份文件的第一至三部分，把它作为来源台账。

目标是通过可信的第三方记录、清晰的中英文企业资料和可被引用的内容提升 Google 搜索、AI Overviews／AI Mode 中的品牌可见度，并准备可执行的外链获取方案。保持网站美观、清晰、有据可查，复用现有设计系统，服务国际 B2B 买家和询盘。请直接检查代码、实现合适的改动并测试。

1. **审查现有网站。** 阅读仓库的 AGENTS.md、README、部署设置及现有构建流程。查看公司简介、About、News、APPPEXPO 2026、SIGN CHINA 2026、第139届广交会及中文对应页，核对实际路由、SEO 标签和现有 Organization JSON-LD。优先更新已有页面，保留现有 URL、表单、询价入口和统计。仓库或账号不可访问时，列出具体缺口，继续完成可独立处理的内容。
2. **把第三方出处放在最相关的页面。** 在现有中英文公司资料页加简洁的「参展与媒体记录／Exhibitions and Media Coverage」模块。第139届广交会文章引用 E12/E13，APPPEXPO 和 SIGN CHINA 文章分别引用对应名录，并说明来源是主办方或第三方。工厂相关页面优先引用 C01/C03。注明届次、年份、展位和来源类型，PDF 有页码则保留。第140届的展位与公司资料仅在该届证据核实后引用。把同源转载、旧产品页、登录入口和待核线索保留在工作台账。可用现有真实参展照片和工厂照片，保留相关产品与询盘入口。
3. **检查抓取、语言版本和企业身份。** 让关键证据、链接及品牌信息出现在静态 HTML。用带有效 `href` 的描述性链接，核对 canonical、双向 hreflang、sitemap、标题和摘要，仅修改发现的问题。复用已有 Organization 标识，统一企业名称、官网、Logo 和已有可信联系方式。`sameAs` 只用于已核实、确实代表同一企业的公开档案或官方账号。展会总名单和媒体报道作为页面出处。核对品牌经营历史与法律主体成立年份的区别，有证据再调整。公司页面不发布未经核实的认证、产能、阻燃或客户声明。
4. **交付站外回链行动表。** 按第三部分逐一核实 APPPEXPO、SIGN CHINA、Mati Logistics、广交会线上档案及其他有价值的页面。记录当前公开页面、目标链接、可操作入口、优先级、下一步和验收证据。准备一份中文主办方请求、一份英文目录更正请求，供我发送。以公司全名或品牌名作为自然链接文字，请对方链接官网首页或对应的参展文章。保持公开网页、官网出站引用、品牌提及和已核实入站回链各自独立。第三方账号、公开发布、对外消息和生产部署留给我确认。遵循 Google 对付费链接及链接垃圾的规定。
5. **验证并给我可审查的结果。** 运行仓库已有检查，核验新增引用是否可访问并指向正确条目，检查受影响页面的中英文内容、移动端、询价入口、canonical、hreflang 和结构化数据。最终给出改动文件、页面、来源对应关系、检查结果、当前已核实的回链和等待第三方处理的事项。如有 Search Console 访问权限，记录链接报告以及品牌和核心产品搜索的基线，后续按已公开回链、相关搜索曝光与询盘跟踪。根据实际证据描述结果。
